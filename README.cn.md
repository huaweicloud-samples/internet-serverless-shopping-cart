## 简介

本项目是基于华为云 FunctionGraph、APIG 和 RDS MySQL 构建的无服务器（Serverless）购物车服务，实现原生电商购物车的核心功能。该方案采用事件驱动架构，利用华为云的无服务器计算能力实现弹性扩展，同时通过消息队列实现异步处理和系统解耦。

### 核心功能

本购物车服务提供完整的电商购物车功能，涵盖用户购物的全生命周期：

1. **匿名购物车** - 未登录用户可创建匿名购物车，系统自动生成临时购物车 ID 并存储在数据库中。匿名购物车支持添加商品、修改数量、删除商品等基本操作，为用户提供了流畅的访客购物体验。匿名购物车设置了 TTL（Time-To-Live）过期机制，7 天无操作自动清理，降低存储占用。

2. **用户购物车** - 登录用户拥有独立的购物车，购物车数据与用户账号绑定。用户购物车没有过期时间，购物记录永久保存。用户购物车支持商品收藏、商品数量管理、商品价格实时同步等功能，为用户提供完整的购物车管理能力。

3. **购物车合并** - 这是本服务的核心亮点功能之一。当用户从匿名状态完成登录后，系统自动将匿名购物车中的商品合并到用户购物车中。合并逻辑智能处理商品重复问题：相同商品累加数量，不同商品保留添加。合并过程通过 DMS RabbitMQ 异步处理，确保高并发场景下的系统稳定性。

4. **TTL 过期处理** - 系统利用消息队列的延迟消息功能实现购物车商品过期处理。当商品即将过期时，系统自动发送通知提醒用户；若用户未在规定时间内处理，商品自动从购物车中移除。该机制帮助电商平台清理长期占用库存的商品，提升库存周转效率。

5. **订单结算** - 用户完成购物后，可将购物车中的商品一键提交订单。结算过程自动计算商品总价、优惠折扣、运费等费用，生成订单后同步扣减库存。订单创建成功后，购物车自动清空或保留用户勾选的商品。

### 技术特点

- **无服务器架构**：采用 FunctionGraph 实现业务逻辑，按需结算，无需管理服务器
- **高可用设计**：多可用区部署，自动故障转移
- **弹性扩展**：基于请求量自动扩展，适应突发流量
- **事件驱动**：通过 DMS RabbitMQ 实现异步处理和系统解耦
- **数据持久化**：使用 RDS MySQL 存储购物车数据，保证数据可靠性

## 涉及云服务

| 服务 | 用途 |
|------|------|
| FunctionGraph | 无服务器函数计算 |
| APIG | API 网关 |
| RDS MySQL | 关系型数据库 |
| DMS RabbitMQ | 消息队列 |
| OBS | 对象存储 |
| VPC | 虚拟私有云 |

## 前置条件

- 华为云账号
- AK/SK 凭证
- cn-north-4 区域

## 快速开始

```bash
# 配置凭证
export HW_ACCESS_KEY="your-access-key"
export HW_SECRET_KEY="your-secret-key"

# 初始化
cd infra
terraform init

# 预览资源
terraform plan

# 部署所有资源
terraform apply

# 获取 API 地址
terraform output apig_url
```

## 部署内容

| 资源 | 数量 |
|------|------|
| VPC/Subnet/SG | 7 |
| RDS MySQL | 1 |
| DMS RabbitMQ | 4 |
| OBS | 2 |
| APIG | 5 |
| FunctionGraph | 4 |

## 使用方法

```bash
# 创建购物车
curl -X POST https://{apig-url}/carts

# 添加商品
curl -X POST https://{apig-url}/carts/{cart_id}/items \
  -H "Content-Type: application/json" \
  -d '{"product_id": "123", "quantity": 2}'

# 获取购物车
curl https://{apig-url}/carts/{cart_id}
```

## 清理资源

```bash
terraform destroy
```
