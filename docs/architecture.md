# 架构说明：购物车服务

## 概述

本文档描述华为云上的无服务器购物车服务架构。

## 系统架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                     华为云 购物车服务                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                  │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │                      APIG (API 网关)                    │ │
│  │  /carts → /items → /checkout → /merge                  │ │
│  └─────────────────────────────────────────────────────────────┘ │
│                                    │                               │
│                                    ▼                               │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │                 FunctionGraph (函数计算)                    │ │
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐    │ │
│  │  │创建购物车│ │添加商品 │ │删除商品 │ │合并购物车│    │ │
│  │  └─────────┘ └─────────┘ └─────────┘ └─────────┘    │ │
│  └─────────────────────────────────────────────────────────────┘ │
│                                    │                               │
│         ┌──────────────────────────┼──────────────────────────┐  │
│         ▼                          ▼                          ▼  │
│  ┌─────────────┐         ┌─────────────┐           ┌────────┐ │
│  │   RDS MySQL  │         │ DMS队列    │           │  OBS   │ │
│  │  (购物车表) │         │ (TTL处理)  │           │(静态资源)│ │
│  └─────────────┘         └─────────────┘           └────────┘ │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

## 组件说明

### 1. API 接入层

| 组件 | 用途 |
|------|------|
| APIG | 统一 API 网关，路由到各个微服务 |

### 2. 计算层

| 服务 | 用途 |
|------|------|
| 创建购物车 | 生成购物车 ID 和 TTL |
| 添加商品 | 写入购物车商品 |
| 删除商品 | 移除购物车商品 |
| 合并购物车 | 登录时合并匿名购物车 |
| 结账 | 创建订单 |

### 3. 数据层

| 组件 | 用途 |
|------|------|
| RDS MySQL | 购物车数据存储 |
| DMS RabbitMQ | 事件队列，用于 TTL 过期处理 |
| OBS | 静态资源存储 |

### 4. 认证层

| 组件 | 用途 |
|------|------|
| 自建 JWT | 自建用户认证服务 |

## 数据流

1. 客户端 → APIG → FunctionGraph
2. FunctionGraph → RDS MySQL 读写购物车
3. 购物车事件 → DMS RabbitMQ → TTL 过期处理
4. 用户登录 → 合并匿名购物车 → 创建订单
